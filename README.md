# Study space

A React + Vite study workspace with a dedicated chemistry notes page.

```sh
npm install
npm run dev
```

Open `/` for the workspace, `/course` for Course Home, `/questions` for practice, `/notes` for the revision guide, or `/flashcards` for recall practice.

The shared course sidebar includes Course Home, Questions, Revision Guide, and Flashcards. Hover or focus it to reveal labels; Show Menu pins it open. Hover a row to pin or unpin that destination. Pinned destinations move to the top, and both pin settings persist across pages and reloads. Pin controls use custom outline/filled thumbtack icons and darken on hover without a background. Row hover fills stay on the navigation row, and its left inset stays fixed throughout expansion. The revision-guide divider is hidden when the guide is collapsed.

Questions includes 200 source-linked MCQs imported from five user-supplied June 2026 Chemistry 0620 papers, alongside 30 original practice questions. Questions are assigned to the tested syllabus subtopic, with independent paper, Core/Extended and difficulty filters. The published mark-scheme keys are recorded in `src/data/past-papers/0620-june-2026-review.json`. Run `scripts/import-0620-june-2026.py --input-dir /path/to/papers` with PyMuPDF installed to rebuild the bank; its formatter creates native wording, numbered lists, chemical subscripts/superscripts and inline SVG diagrams from reviewed PDF geometry. Tables remain whole, with A–D choices underneath. No question or option screenshots are rendered. Find question opens the unmodified source paper at its original page. Answer selection, deselection, retries, bookmarks, local history and topic progress remain available. First-attempt percentages are difficulty estimates, not collected student statistics.

Filter selects and action menus share `DropdownSurface` and `DropdownSurfaceItem` in `src/components/ui/dropdown-surface.jsx`. Edit `src/components/ui/dropdown-surface.css` to change the border, radius, item spacing, typography, hover treatment or top-origin animation across all dropdowns. Select menus match their trigger width; action menus keep enough width for their labels.

The calculator buttons open one shared, draggable and resizable scientific simulator above the questions. Drag its header, resize from the bottom-right handle, or focus either handle and use arrow keys (Shift for larger steps). Size and position persist locally; calculations restore within the current browser tab. The locally hosted [Casio-inspired fx-82TS simulator by Simon Cragg](https://github.com/simoncragg/scientific-calculator) is MIT licensed, with source and licence preserved in `vendor/casio-simulator` and credits in `/calculator/NOTICE.txt`. It runs in an isolated iframe, loads on demand, and scales its keys/display as its window resizes. It supports scientific keys, keyboard input, memory, Ans and angle modes. Rebuild its checked-in assets with `npm run build:calculator` after installing its separate locked dependencies as described in its README.

Design constraint: never wrap note content or diagrams in empty, border-only boxes. Use open layouts or soft filled surfaces. The revision guide collapses completely, with no remaining spacer. Its plain arrow toggle stays outside the panel edge in both states and uses a soft rounded hover surface. The text and annotation toolbar share a grid column and move together. Topbar and navigation stay inside a fixed viewport; the notes and revision-guide list have independent scroll containers. The revision guide reveals a fixed-width panel without resizing or shifting its inner content. It uses a fixed 258px desktop width, drops the collapsed spacer when opened, and truncates lesson labels within the full rounded active row. The guide index uses the official 2026–2028 Cambridge IGCSE Chemistry 0620 structure: 12 chapter dropdowns with 49 flat, numbered subtopic links and completion circles. There is no third numbering tier. Chapter expansion persists locally; the selected chapter opens when navigating to a subtopic. Subtopic selection stays in the current mode: `/notes?topic=11.1` or `/questions?topic=11.1`. Switching modes in the sidebar keeps the same topic. Questions are strictly filtered by their `subtopicId`, with an honest empty state for topics that have no questions yet. The existing detailed organic guide is retained at 11.1; other subtopics have concise topic overviews, official syllabus page links, previous/next navigation and saved completion. The shared Questions/Notes/Flashcards title now uses the official 11.1 title. The navigation rail expands on hover or keyboard focus without tooltips, and its menu button pins it open. Ratings change the thumb icon stroke to green (up) or red (down), with no background fill. Notifications stack only when multiple real messages are active; each expires independently. The annotation toolbar uses Find questions instead of an assistant. It briefly shows a shimmering Searching… state, then opens the questions tagged for that syllabus subtopic. The same action is available on other topic overviews. It runs locally without an AI service; highlighted-text matching is reserved for a later feature.

The notes use Google Fonts Manrope, shadcn/Radix controls, custom SVG characters and status icons, and responsive layouts. Click **Highlight** to enable highlight mode, then select text to save it automatically in the chosen colour. Click Highlight again or press Escape to exit. Hover saved highlights for a pointer; click one to change its colour or delete it. The lesson menu’s **Your highlights** list lets you return to and manage saved annotations. Selections can span paragraphs and formatting; overlapping selections replace only the overlapping part of earlier annotations. Highlights and colour edits save locally, including their text context so they can be restored after small lesson edits. The outline and reading markers navigate the lesson; the options menu supports bookmarks, copying links, printing, and clearing highlights. The expanded navigation, example cards, common mistakes, exam tips, and guide rating follow the supplied references. Guide ratings also save locally.

Bookmarks, highlights, lesson completion, XP, and the daily study streak persist in browser local storage. Completing the lesson awards 20 XP once. Energy is a display-only starting balance.

Worksheets are available at `/worksheets?topic=11.1`, with the shared topic navigation, difficulty filters, a horizontal preview picker, and a complete PDF reader. Six original two-page samples are included for 11.1. Other topics show an empty state until their PDFs are registered. To add premade worksheets, put PDFs in `public/worksheets/` and add entries in `src/data/worksheets.js`. Picker covers use the shared HTML/CSS `WorksheetCover` component, with topic, difficulty and subject/board/qualification metadata; keep each ID stable so share links and local highlights continue to work. PDFs need a text layer for text highlighting (image-only scans need OCR beforehand). Highlight mode, editing colours, deleting, saved-highlight navigation, zoom, PDF download and Copy link work in the reader. Annotations save separately for each worksheet on this device; they do not modify the downloaded original PDF. The PDF renderer and worker are hosted locally. The sample generator is `scripts/create-sample-worksheets.py` (requires ReportLab and PyMuPDF).

Organic chemistry notes now cover 11.1–11.8 against all 50 numbered Core/Supplement objectives in the official Cambridge 0620 syllabus for 2026–2028. Content and objective references are in `src/data/organic/lessons.jsx`; shared definition boxes, tables, self-checks and atom/bond SVG diagrams are in `src/components/notes/OrganicBlocks.jsx`. Each lesson has its own saved highlights, bookmarks, rating and completion state. The 11.1 storage keys and one-time completion reward remain compatible with existing progress. Extended sections are labelled, and every topic ends with self-check questions and revealable explanations. The source syllabus and objective counts are recorded with the lesson data.

## Subject homepage

The homepage offers Chemistry 0620, Biology 0610 and Physics 0625, with the shared account profile, XP and streak controls. It uses the favicon as the brand icon, a subtle animated background, and a brief cancellable “Loading app” transition. Reduced-motion preferences are respected.

Chemistry keeps its existing URLs and content. Biology and Physics have course overviews and every numbered syllabus topic/subtopic, with introductory text and links to the official syllabus pages; full notes and questions are not included yet. Biology contains 21 chapters and 62 subtopics. Physics contains 6 chapters and 71 numbered topic/area entries, including its third-level syllabus headings. These come from the official 2026–2028 [Biology 0610 syllabus](https://www.cambridgeinternational.org/Images/697203-2026-2028-syllabus.pdf) and [Physics 0625 syllabus](https://www.cambridgeinternational.org/Images/697209-2026-2028-syllabus.pdf).

Subject-aware URLs use `?subject=biology` or `?subject=physics`, followed by `&topic=1.1` on study pages. Course navigation, last-studied resource links and completion are stored separately for each subject. Existing Chemistry progress stays compatible. Worksheets and Flashcards remain disabled across all three subjects. Appwrite handles account authentication and cloud study progress; guest progress remains on this device.

## Accounts, progress and publication pages

Appwrite sign-in now stores study progress in private account preferences (`studyProgress`, version 1). No new database columns or administrative API key are needed. Existing profile XP/streak data is migrated on first use where accessible; newly created accounts can carry over that browser’s guest progress. Answer records, attempts, note completion, reward history, bookmarks, reported-question flags and last study locations sync after a short debounce. Profile totals derive from those records. Removing answers and unmarking notes are saved too. Each account has a separate browser namespace; signing out restores guest progress instead of exposing the previous account’s study records. Highlights and display settings remain local.

The profile shows saving/saved/error status and offers Retry sync. Reconnecting retries failed saves. The implementation merges the most recently updated record for each storage key; simultaneous edits to the same subject’s answer map from two devices are not a collaborative editing system. Appwrite account preferences have a 64 kB limit; payloads above a conservative 62 kB show an error and retain local data. Move progress into a dedicated private collection before the bank substantially outgrows this capacity. XP and streak records are client-managed; introduce server-validated reward events before using XP for prizes or competitive rankings.

The homepage has IGCSE/coming-soon level choices and a Features menu. Worksheets and Flashcards remain disabled. Privacy, Terms, Cookies and Contact pages are linked in the homepage footer and profile menu. They identify Petale Media, Denmark, and petalemedia@gmail.com. The cookie panel stores a versioned choice for 180 days and can be reopened from Cookie settings. There are currently no optional analytics or advertising scripts; allowing optional cookies records a preference only. Essential sign-in and requested study storage work with either choice.
